## Keep the names straight first

- Mailbox domain: `your-domain.com`
- Public mail host: `mail.your-domain.com`
- Runtime hostname: often the same as the public mail host, but not conceptually the same thing

People send mail to addresses on `your-domain.com`.
Mail systems talk to `mail.your-domain.com`.

## Create the domain before you publish records

```bash title="Create and inspect the domain"
sudo lightr domain create --name your-domain.com --mail-hostname mail.your-domain.com --spam-policy junk
sudo lightr domain dns your-domain.com
```

Lightr generates the records it expects for that domain, but it does not push
them into your DNS provider for you.

## Baseline record set

```txt title="Typical records"
mail.your-domain.com.        IN  A     203.0.113.10
your-domain.com.             IN  MX    10 mail.your-domain.com.
your-domain.com.             IN  TXT   "v=spf1 ip4:203.0.113.10 -all"
_dmarc.your-domain.com.      IN  TXT   "v=DMARC1; p=quarantine; adkim=s; aspf=s"
default._domainkey.your-domain.com. IN TXT "v=DKIM1; k=rsa; p=<public-key>"
```

Reverse DNS is set with the VPS provider, not in your zone file:

```txt
203.0.113.10 -> mail.your-domain.com
```

## Verify what you published

```bash title="Verify DNS state"
sudo lightr domain verify your-domain.com
```

Today verification requires:

- MX
- SPF
- DKIM
- DMARC

`PTR` is checked and reported, but it is not currently required to mark a
domain verified.

## Rules that save time

- Use a dedicated mail host like `mail.your-domain.com`.
- Keep the same public name across MX, TLS, SPF-facing docs, and PTR where applicable.
- Do not treat mailbox addresses and mail hostnames as the same field.
- Test against at least two external providers before assuming delivery is healthy.

## Deliverability checklist

- port 25 is actually open for outbound mail at the provider
- MX points to a host with matching A or AAAA records
- SPF includes the real sending IP
- DKIM uses the selector Lightr generated
- DMARC policy matches how strict you want enforcement to be
- PTR resolves back to the same public mail host
